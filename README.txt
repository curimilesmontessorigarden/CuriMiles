LITTLE OAKS EARLY LEARNING — STATIC WEBSITE

A Bootstrap 5 / HTML / CSS / JavaScript concept site tailored to parents of children aged 2+ and 3+.

FILES
- index.html: page content and layout
- css/style.css: custom styles and responsive layout
- js/script.js: hero carousel, current year and simple on-page search

HOW TO USE
1. Keep index.html, css/ and js/ at the same level in your GitHub repository.
2. Commit changes to the branch and folder configured in GitHub Pages.
3. The live site updates after Pages deployment completes.

NOTES
- “Little Oaks Early Learning” is sample branding; replace it with your real centre/site name.
- Photos, fonts, Bootstrap and icons use external CDNs and require internet access.
- Enquiry links are placeholders; no form or data submission is configured.
- This is a design concept, not a claim about actual services, staffing, qualifications or availability.
